# Helicopter Prison Escapes Analysis

## Description

This project analyzes helicopter prison escape attempts using data extracted from a Wikipedia page:  
**List of helicopter prison escapes**.

The goal of this project is to clean, explore, and analyze the dataset in order to answer several questions about helicopter prison breaks.

The analysis focuses on:
- the number of escape attempts over time,
- the countries where helicopter prison breaks are most frequent,
- the countries with the highest success rate,
- the relationship between the number of escapees and success,
- escapees who may have attempted it more than once.

## Dataset

The data was collected from the Wikipedia page:

`https://en.wikipedia.org/wiki/List_of_helicopter_prison_escapes`

The dataset contains information such as:

- Date of the escape attempt
- Prison name
- Country
- Whether the escape succeeded
- Escapee(s)
- Details about the escape
